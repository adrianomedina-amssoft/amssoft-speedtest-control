# Politica de seguranca

Relate vulnerabilidades de forma privada para a AMS SOFT pelos canais oficiais de
suporte. Nao publique credenciais, chaves de licenca, dados de clientes, provas de
conceito funcionais ou detalhes que facilitem exploracao em issues publicas.

Somente a release estavel mais recente recebe manutencao. Antes de relatar um
problema, confirme a versao instalada sem anexar bancos, logs crus, cookies,
tokens, chaves privadas ou arquivos `.env`.
