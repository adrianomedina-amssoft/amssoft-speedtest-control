# Distribuição oficial

Este é o repositório oficial de distribuição do AMS SpeedTest Control, uma
solução comercial para gerenciamento e acompanhamento de medidores de
velocidade.

## Conteúdo disponível

Este repositório disponibiliza:

- o instalador oficial do produto;
- documentação pública de instalação e segurança;
- a chave pública utilizada para verificar a autenticidade das releases;
- acesso às releases estáveis destinadas aos clientes.

Os pacotes publicados passam por verificações de integridade e assinatura antes
de serem disponibilizados.

## Software comercial

O AMS SpeedTest Control é software comercial proprietário. O código-fonte não
faz parte desta distribuição e o uso das funcionalidades depende de uma licença
válida fornecida pela AMS SOFT.

## Suporte e segurança

Utilize os canais oficiais da AMS SOFT para atendimento comercial e suporte.
Vulnerabilidades ou informações sensíveis não devem ser publicadas em issues.
Consulte a [Política de Segurança](SECURITY.md) para orientações.
